# Как скачать и играть

## Играть на сайте

1. Откройте [3D-витрину игр](https://ilyabarilo.github.io/games/).
2. Выберите стенд на карте или в списке игр. Можно также нажать на пол,
   чтобы подойти к нужному месту, и потянуть сцену для осмотра.
3. Если у игры есть сложности, выберите одну из круглых кнопок на экране стенда.
4. Нажмите «Играть» перед экраном. «Информация» открывает страницу об игре.
5. Кнопка «Назад» браузера возвращает в павильон на прежнее место.

На компьютере W/S и стрелки вверх/вниз перемещают по павильону,
A/D и стрелки влево/вправо поворачивают. На сенсорном экране можно использовать
джойстик слева внизу. Колесо мыши или жест двумя пальцами приближают вид
и возвращают к исходному масштабу. Для 3D-витрины нужен браузер с JavaScript и WebGL.

На странице «Информация» есть QR-код для запуска игры на телефоне.
Нажмите на небольшой код, чтобы увеличить его, и отсканируйте камерой телефона.
Ссылка открывает игру на сайте; для загрузки нужен интернет.
Рядом с кнопкой «Играть» можно выбрать «Скачать игру» и сохранить её HTML.

## Скачать одну игру

Каждая игра коллекции работает из одного HTML-файла. Обложки из репозитория
для запуска игры скачивать не требуется.

| Игра | Файл в репозитории |
|---|---|
| Змейка 3D | [snake3d-turns.html](https://github.com/IlyaBarilo/games/blob/main/games/snake3d-turns/snake3d-turns.html) |
| Крестики-нолики с сапёром | [tictac.html](https://github.com/IlyaBarilo/games/blob/main/games/tictac/tictac.html) |
| Змейка: эволюция видеоигр | [snake-evolution.html](https://github.com/IlyaBarilo/games/blob/main/games/snake-evolution/snake-evolution.html) |
| Диагностика интерактивного экрана | [interactive-screen-benchmark.html](https://github.com/IlyaBarilo/games/blob/main/games/interactive-screen-benchmark/interactive-screen-benchmark.html) |
| Робосклад | [tictac-robots.html](https://github.com/IlyaBarilo/games/blob/main/games/tictac-robots/tictac-robots.html) |
| Шарики с поздравлениями к 8 Марта | [8march-shariki.html](https://github.com/IlyaBarilo/games/blob/main/games/8march-shariki/8march-shariki.html) |

1. Откройте нужный файл по ссылке из таблицы.
2. На странице GitHub нажмите «Download raw file» — кнопку скачивания исходного файла.
   Сохраните файл с расширением `.html`.
3. Откройте скачанный HTML в браузере. На компьютере обычно достаточно двойного
   щелчка; при необходимости выберите браузер через «Открыть с помощью».
4. Выберите режим в самой игре, если он предусмотрен, и следуйте её подсказкам.

Для запуска отдельных HTML интернет не требуется. Браузер должен поддерживать
JavaScript; для «Змейки 3D» также нужен WebGL. Способ открытия локального HTML
на телефоне зависит от системы и браузера; для коллекции на телефоне можно использовать GameSpace.
Полные условия автора и сторонние уведомления уже находятся внутри файлов игр.
Исключение — текущий HTML диагностического теста: полный текст условий автора
в него пока не встроен; для него также действуют [условия коллекции](LICENSE.md).

## Скачать готовую коллекцию

1. Откройте [последний стабильный выпуск](https://github.com/IlyaBarilo/games/releases/latest).
2. Скачайте [games-gamespace-latest.7z](https://github.com/IlyaBarilo/games/releases/latest/download/games-gamespace-latest.7z)
   — комплект последнего стабильного выпуска. В Assets каждого выпуска также
   сохраняется архив с его тегом: `games-gamespace-<тег>.7z`.
3. Для запуска на компьютере распакуйте архив целиком с сохранением папок.
4. Для запуска напрямую с диска откройте `gamespace.html` из распакованной папки:
   появится 2D-витрина.
5. Выберите сложность и запустите игру. Сохраняйте остальные файлы рядом с витриной.

Комплект GameSpace содержит 3D-павильон, 2D-витрину, игры и описания. В GameSpace
при первом открытии `index.html` запускается 3D-павильон. Кнопка «GameSpace»
переключает на 2D, а «В 3D-павильон» возвращает в зал. Последний выбранный режим
сохраняется в `localStorage` и открывается при следующем входе.

Для 3D нужны JavaScript и WebGL. При открытии `index.html` напрямую с диска
браузер может блокировать изображения в 3D-сцене: используйте GameSpace
или веб-сервер. 2D-витрина `gamespace.html` работает при открытии с диска.

`games-web-<тег>.7z` содержит готовую веб-версию коллекции для размещения на сервере.

Готовые архивы уже содержат необходимые файлы. Node.js, npm и самостоятельная
сборка для игры не требуются. Автоматические архивы GitHub «Source code»
предназначены для исходников; готовая коллекция находится в названных выше `.7z`.

## Открыть коллекцию в GameSpace

1. Установите подходящий вариант [GameSpace](https://github.com/IlyaBarilo/gamespace):
   PWA для поддерживаемых телефонов и планшетов или APK для Android.
2. Скачайте [games-gamespace-latest.7z](https://github.com/IlyaBarilo/games/releases/latest/download/games-gamespace-latest.7z)
   — комплект последнего стабильного выпуска коллекции.
3. Запустите GameSpace и выберите собственный архив через системный файловый диалог.
4. Дождитесь установки содержимого и откройте коллекцию: при первом запуске
   появится 3D-павильон. В нём можно перейти в 2D-витрину кнопкой «GameSpace».

Распаковывать архив вручную для GameSpace не нужно. После установки приложения
и импорта коллекция работает на устройстве без постоянного подключения к интернету.

## Условия использования

Разрешены личное некоммерческое использование, изучение игр и обычные занятия
со своей группой обучающихся или воспитанников в образовательных организациях
и кружках, включая дополнительное образование.

Показы другими выступающими и организаторами на мероприятиях, распространение
копий и другие случаи за пределами разрешений требуют письменного согласования
с Ильёй Барило. Скачивание игры само по себе такого разрешения не даёт.

Полные [условия автора](LICENSE.md) и [сторонние лицензии](NOTICE.md)
сохранены в готовых комплектах и внутри HTML игр в применимой к ним части.
